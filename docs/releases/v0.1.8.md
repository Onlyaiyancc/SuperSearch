# SuperSearch v0.1.8

## 更新内容

- 屏幕扫码：一次识别鼠标所在屏幕上的网址文字和二维码，网页链接优先展示，每条可复制或打开。
- 改进小字号 OCR，修复已复现的 `j`/`i` 主机名误识别，保留不同网址与文字边界；识别结果不会自动打开。
- Alt+Space 窗口展开或收起时围绕当前视觉中心调整，结果更便于阅读。
- 格式转换支持图片、PDF、Office、Markdown、网页文档和 OCR；组件可一键安装，随附组件优先使用本地包。
- 增强图片、文本、PDF 和 Office 文件预览，增加提醒/倒计时、翻译/查词扩展。
- 扩展命令同时提供中文和英文：`扫码 / scan / qr`、`转换 / convert`、`翻译 / translate`、`查词 / dictionary`、`提醒 / remind`、`倒计时 / timer`。

## 下载与升级

- **完整便携包：** `SuperSearch-full-x64.zip`，随附 PDF/OCR 组件；解压后保留 `components` 和 `licenses` 文件夹，运行 `SuperSearch.exe`。Markdown/Pandoc 与 Office 按需从官方来源一键下载安装。
- **安装程序：** `SuperSearch_0.1.8_x64-setup.exe`，提供专用 Everything 索引服务；可从本版本附件安装可选组件。
- **仅更新程序：** 已有新版 OCR 1.0.1 组件的用户可退出旧版后替换 `SuperSearch.exe`；旧本地测试包用户建议完整解压本次完整包。
- **校验：** 对照 `SHA256SUMS.txt` 检查下载文件。

第一次使用屏幕网址识别会准备本地 OCR 组件。系统需有 Microsoft WebView2；安装程序会在缺失时下载运行库。退出旧版托盘进程后再升级，现有设置、固定项目和历史保留。

## 验证与限制

本版本的确切构建、测试、组件来源及安装验收结果见 Release 附件 `Release-Acceptance.md`。公开附件只包含已完成分发材料的组件，并保留各自许可与来源；对应源码材料随附件提供。

OCR 仍可能误读，打开链接前请核对地址。多屏幕、真实 150%/200% 混合缩放、交互式 UAC、休眠唤醒及长时间资源表现未由本次自动测试完整覆盖。程序和安装包未签名。翻译/查词扩展仅在明确提交后访问对应服务；屏幕识别和文件转换在本机处理。
