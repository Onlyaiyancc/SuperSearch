# SuperSearch v0.1.6-beta.1

First public Pre-release for Windows x64.

- Chinese application/file/folder search with pinyin, initials and alias matching.
- Bundled Everything engine; the machine installer provides a dedicated NTFS/USN indexing service. Portable mode can use isolated directory scanning.
- History-first ranking, configurable shortcut, light/dark/system appearance, folder completion and explicit web-search fallback.
- Fixes for preserving existing aliases, empty-page pagination and settings status refresh while indexing completes.

Downloads include an NSIS installer, a portable ZIP with license notices, and SHA-256 checksums. The executable is unsigned. Exit any older instance from the tray before upgrading. The installer requests administrator permission; Microsoft WebView2 is required.

This is a beta. Synthetic automated checks do not establish physical IME/multi-monitor behavior, installation lifecycle or long-duration memory behavior. Please report reproducible problems using the repository issue template after removing personal data.

Dependency audit: npm reported no known vulnerabilities during local preparation. RustSec reported five warnings in the full cross-platform lockfile (proc-macro-error, zbus_names, zvariant, zvariant_derive and glib); these packages were absent from the resolved Windows MSVC dependency graph. They remain tracked upstream and must be reassessed before supporting other platforms.
