# SuperSearch v0.1.7

Windows x64 stable release, published on 2026-10-20. The program is unsigned. Download the installer, portable ZIP, acceptance report and checksums from [GitHub Releases](https://github.com/Onlyaiyancc/SuperSearch/releases/tag/v0.1.7).

- Raises the application and installer versions to 0.1.7 so upgrades from the 0.1.6 beta can be verified as real version changes.
- Verifies candidate asset names and executable versions against the exact source commit during disposable Windows installation acceptance. Same-version replacements no longer qualify as upgrade evidence.
- Adds separate engine startup, observed provider readiness and fixture visibility timings to NTFS diagnostics. Failed cold-index probes retain their last state and query errors; the 120-second deadline remains unchanged.
- Keeps stable releases as drafts for review. Beta tags retain the existing pre-release behavior.
- Keeps manual engine restarts in a loading state across short status-query timeouts, so the visible settings panel can continue checking until readiness or a real failure.
- Restores canonical logical window dimensions after display/DPI changes and offers remembered or mouse-monitor recall positioning in general settings.
- Centers on the remaining target display when the remembered display disappears, including when Windows has already relocated the window to a corner. Normal cross-display dragging and valid remembered positions remain supported.

The program is unsigned. Exit the old instance from the tray before upgrading. Administrator permission is required for the machine installer and dedicated Everything service; WebView2 is required. Keep all license notices with the portable ZIP.

Published application source: `651580dd56a157449a46aca43b350b45482beb7c`. The [candidate build](https://github.com/Onlyaiyancc/SuperSearch/actions/runs/39364003496) and [cloud installation acceptance](https://github.com/Onlyaiyancc/SuperSearch/actions/runs/39371289628) passed. The exact installer was verified for 0.1.6 → 0.1.7 upgrade, settings/aliases/pins/history retention, dedicated NTFS queries, uninstall coexistence and fresh installation. Disposable Windows Server 2025 testing verified real WebView2 removal, blocked-download cleanup, online recovery and native rendering. The public release's four attachments were downloaded again and their SHA-256 digests matched the accepted draft.

The exact portable executable passed a short native UI/resource diagnostic. Previous beta and older-candidate 30-minute reports do not establish long-duration behavior for this binary. The maintainer reported local candidate IME, shortcuts/single-instance, persistence, sleep/wake, engine restart, display hot-plug/positioning and interactive UAC normal; running hashes for those physical checks were not independently confirmed. Separate 150%/200% DPI and interactive dependency-error wording remain unverified, and Server 2025 testing does not establish every Windows 10/11 combination. See the attached Release-Acceptance.md for the evidence scope.

Original code is MIT; third-party components retain their own terms. The release acceptance records a clean full npm audit and dependency-notice check, plus five documented Rust full-lockfile warnings outside the Windows MSVC dependency graph.
