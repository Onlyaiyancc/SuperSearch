# SuperSearch v0.1.7

Stable release for Windows x64. The application interface is Simplified Chinese. **The application and installer are unsigned.**

## Changes

- Fix search-engine restarts being reported as unavailable after a short status timeout. Advanced settings continue refreshing while the engine becomes ready.
- Fix incorrect window dimensions and corner positioning after disconnecting a secondary display.
- Add a display-position setting: remember the last position or center on the monitor containing the pointer when recalled.
- Improve version-upgrade validation and cold-index diagnostics.

## Downloads and upgrade

- **Installer:** download `SuperSearch_0.1.7_x64-setup.exe`. Exit the old instance from the tray before upgrading. Installation requires administrator permission and registers a dedicated `Everything (SuperSearch)` indexing service, separate from personal Everything.
- **Portable:** extract the complete `SuperSearch-portable-x64.zip`, retain the included license files and run `SuperSearch.exe`. Microsoft WebView2 must already be installed. Without the dedicated service, file search uses directory scanning.
- **WebView2:** the installer downloads the runtime if it is missing. If the download fails, restore network access and retry.
- **Checksums:** compare downloaded files with `SHA256SUMS.txt`. Unsigned binaries may trigger unknown-publisher or Windows SmartScreen prompts.

Initial indexing may take several minutes. The advanced settings panel updates automatically; reopening it is unnecessary.
