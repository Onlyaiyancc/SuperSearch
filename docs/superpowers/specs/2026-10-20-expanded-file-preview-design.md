# 扩展文件预览

用户已选择同时实现 PDF/图片/大文本和 Office 内容预览。

## 行为

- 继续使用现有空格、结果菜单和 Esc 返回；卡片默认仅显示标题、简介与开关。
- PDF：100 MiB，使用 Windows 本地 PDF 渲染能力，提供页码与前后翻页。仅渲染当前页，预览关闭或搜索变化时取消迟到结果并释放文档缓存。密码保护或损坏文档显示中文提示及打开文件入口。
- DOCX/XLSX/PPTX：50 MiB，离线提取文字和表格。DOCX 显示正文，XLSX 可选工作表，PPTX 按幻灯片列出文字。首版不承诺原始排版；不支持旧版 DOC/XLS/PPT、宏执行、外部链接加载。ZIP 条目、解压总量、XML、输出文字和表格行列均有独立边界，达到边界时显示节选提示。
- 图片：50 MiB，扩展原有支持并增加本机可解码的 TIFF/ICO；保持原有小图自适应高度。大图使用有界缩略图，避免将完整大图反复发送给 WebView；无法解码则提示打开文件。
- 文本：增加常见代码、配置和网页源码扩展名；HTML/SVG 仅显示源码。支持最多 1 GiB 的本地文本文件，每次读取约 1 MiB 并提供片段切换，保留 UTF-8/UTF-16 并增加常见中文编码支持。片段边界不能破坏多字节字符。

## 边界

原生入口仍由有效搜索 requestId/resultId 授权，不接受前端任意路径。仅常规本地文件，沿用链接/设备/网络路径限制。新增 previewId 区分同一结果的不同打开操作；关闭、隐藏及查询失效时清理缓存。磁盘、解压和渲染任务不占用全局搜索/设置锁；同类任务限制并发，迟到结果不能覆盖新的预览。

## 验证

使用合成 PDF、Office 压缩包、编码文本和图片夹具验证真实原生处理。前端验证分页、工作表、文本片段、节选提示、空格/Esc、迟到回包以及浅色/深色/窄窗口。运行前端测试/类型检查与构建、Rust 测试/check，更新依赖许可并生成本地程序和安装包。不发布正式版本或改写用户已有文件。
