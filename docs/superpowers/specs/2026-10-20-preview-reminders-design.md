# 文件快速预览与倒计时提醒

状态：用户已确认；第一版已实现，验证范围见 docs/design/qa.md。

## 范围与方案

两个独立可选内置插件，默认关闭，沿用翻译插件的紧凑卡片。卡片默认仅图标、名称、简介、开关，点击标题展开说明；启用状态随设置保存或取消。

推荐在现有窗口内预览、原生后台管理提醒。独立预览窗口会增加焦点与多屏管理成本；仅浏览器计时无法可靠覆盖窗口隐藏或前端重载，因此不采用这两种方式。

## 文件快速预览

- 支持 PNG/JPEG/GIF/WebP/BMP 图片、UTF-8/带 BOM 的 UTF-16 文本、Markdown。首版不包含 PDF、Office 和 SVG。
- 用户通过方向键或鼠标明确选中文件后，空格打开预览；同时提供结果菜单中的“快速预览”。搜索框正常输入空格继续输入查询，自动选中的首项不截获空格。
- 预览在当前窗口显示文件名、图片或可滚动正文。Markdown 禁止原始 HTML、脚本和远程资源加载。Esc 返回原查询与选中项，再次 Esc 隐藏窗口。
- 图片读取上限 10 MiB，正文读取上限 1 MiB；超限、未知编码、文件被移除、权限不足或格式不支持时显示中文提示并保留“打开文件”入口，不执行文件。
- 原生端通过当前 requestId/resultId 解析文件；不允许前端提交任意路径读取。只读取常规本地文件，拒绝目录、网络位置和设备路径。验证插件启用与查询有效性后在后台线程有界读取，文件内容仅驻留本次预览。
- 查询变化、关闭、隐藏或打开设置时丢弃迟到结果。复用现有窗口尺寸上限和浅色/深色主题。

## 倒计时提醒

- 输入“提醒 20分钟 休息”或“倒计时 30秒”，显示待创建预览，按 Enter 或按钮才创建。支持秒、分钟、小时和组合时长；无标题使用“倒计时结束”。
- 输入完整命令词“提醒”或“倒计时”进入列表，查看剩余时间并取消。命令需独立词或后接空白，不截获以这些文字开头的普通文件名。
- 允许同时存在至多 20 个提醒，时长 1 秒到 7 天，标题最多 100 个字符。校验失败显示输入提示，不自动创建。
- Rust 后台按到期时间调度，窗口隐藏后继续工作，不抢占输入焦点。到时发送 Windows 桌面通知，并在提醒列表保留完成状态；系统通知关闭时列表仍可查看。
- 本地保存提醒，重新打开程序后恢复未完成项；退出期间已到期的提醒启动时合并提示一次。程序完全退出期间无法即时通知。电脑睡眠后，在恢复运行时处理到期项。
- 禁用插件时取消待执行提醒，并在保存前明确显示该影响；设置取消则保留提醒。创建、取消、到期处理保持一致，避免重复调度和通知。

## 结构与验证

前端各自使用独立面板和状态模块，接入现有命令识别、设置和键盘路由。Rust 各自使用独立模块；提醒使用现有 SQLite 存储，通知优先使用维护中的原生集成。避免引入通用插件框架和无关重构。

验证包含：命令边界与 IME、普通搜索空格、显式选择快捷键、文件读取上限与错误编码、Markdown 安全渲染、迟到回包、提醒取消/重复提交/恢复/到期去重、设置保存取消；运行前端和 Rust 测试、类型检查与构建，并检查浅色、深色、窄窗口。浏览器模拟和实际 Windows 通知验证分别记录，不互相替代。
