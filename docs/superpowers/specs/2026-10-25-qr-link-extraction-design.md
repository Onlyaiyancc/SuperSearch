# 二维码内容提取网页链接

用户于 2026-10-25 明确选择：从扫码内容提取网页网址，支持混合文字和多个链接，并单独复制或打开。

- 每条扫码结果提供「提取网页链接」，原始内容保留。输入、扫描完成和切换结果都不自动执行提取或打开。
- 提取结果在对应二维码下展示域名和完整网址，每条提供「复制链接」「打开链接」。无匹配时明确提示；重新扫描和退出后清除旧链接。
- 仅识别显式 HTTP/HTTPS 地址，兼容协议大小写、中文说明、常见包围标点和 Markdown/JSON 中的地址；规范化后去重并保留出现顺序。每个二维码最多 16 条，超出时提示。
- 原文最多 16 KiB。拒绝隐蔽控制字符、带用户凭据的地址和非网页协议。保留原文复制入口，不把提取规则用于修改原始扫码内容。
- 原生端读取当前会话与二维码凭据进行提取；链接操作只携带会话、结果和链接 ID，目标 URL 必须从原生缓存内容重新解析。前端不能提交任意网页目标。
- 纯本地处理，不请求网页、不跟踪短链跳转、不获取浏览器地址、不保存历史。显示规范化网址与域名；打开始终由用户明确点击。
- 与现有扫码共享忙状态和会话失效逻辑，迟到提取或链接动作回复不能恢复旧界面。输入框 Enter 仍复制当前二维码原文。
- 测试覆盖多网址/去重/空结果/标点/协议/凭据/上限、伪造及过期凭据、动作重试、退出和重新扫描、明暗/窄窗口及浏览器预览无系统副作用。
