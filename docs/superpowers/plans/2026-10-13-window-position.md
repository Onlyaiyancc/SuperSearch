# Remember the position between window invocations

用户指定拖动后再次呼出仍在该位置。复用现有原生窗口坐标，不新增插件或磁盘状态：同一次程序运行中，首次呼出使用默认位置，后续呼出保留当前位置；设置和单实例呼出走同一规则。显示器移除或工作区变化时，继续用现有 fit 工作区约束。完全退出后重启保持现有首次定位行为，本次不扩展为跨进程位置偏好。

根因是 show 总以 opening=true 调用 apply_layout，导致丢弃当前位置并优先选择鼠标所在屏幕。以一个原生初始化状态区分首次定位和再次显示；状态仅在首次布局成功后提交。窗口大小与内容重置规则继续使用现有逻辑。

验证：运行现有布局回归检查默认布局、保留锚点及工作区夹取；Rust 完整测试，前端检查，独立代码复核，构建 0.1.3 程序和安装包，交付文件哈希与原生几何检查。此次修正原生呼出入口的定位参数，不增加镜像实现的布尔测试。原生拖动交互因当前工具不支持仍需用户真机检查，不以几何测试替代。
