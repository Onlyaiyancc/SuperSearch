# Bing fallback and single search surface

用户明确指定三项改动，按此直接实施：移除检查设置与 Alt+Space 栏内提示；无结果 Enter 打开默认浏览器进行 Bing 搜索，Shift+Enter 强制搜索；移除搜索栏外侧的背景与留白。

- 窗口仅保留内部搜索表面：默认宽 880、高 80 逻辑像素，透明背景、无系统装饰、禁止用户拖动尺寸但保留程序自动展开。结果窗口高 174+60×可见行数，最多六行；设置/弹窗仍为 620。关闭会带来系统额外描边的原生阴影，取消原 16/18px 外侧留白，保留搜索表面自身细边框。
- 空输入不显示快捷键或依赖文字。依赖状态留在设置与无障碍反馈中。加载可显示小图标；最终无结果显示轻量“↵ 必应搜索”操作。
- 普通 Enter 仅在当前查询结束且零结果时转网页搜索；等待结果时不误触发。Shift+Enter 对任意非空输入强制网页搜索，包括有本地结果、加载或本地语法错误；Ctrl+Enter 仍只定位本地结果。空输入、输入法合成、重复 Enter 与忙碌期间不启动浏览器。
- 内部命令 search_web(rawQuery) 只生成固定 https://www.bing.com/search 的 q 参数；使用 Tauri 已有 Url 编码，不接受任意 URL 或 shell 命令，不新增依赖。浏览器成功受理后隐藏窗口，不写入本地文件使用统计。
- 先写键盘与 URL 编码行为回归并观察失败，再实现；核对尺寸、排版、预览隔离、键盘、设置、中文输入合成；更新 0.1.2 程序、安装包与报告。真实网页搜索使用用户显式按键触发，测试使用隔离模拟 IPC。
