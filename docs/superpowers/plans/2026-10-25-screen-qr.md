# Screen QR scanning implementation plan

> **For agentic workers:** Use subagent-driven-development to execute these tasks in the current session. Preserve all existing uncommitted changes. Do not commit or publish this working tree.

**Goal:** Add the approved optional current-monitor QR scanner, displaying results before explicit copy or HTTP/HTTPS opening.

**Architecture:** Native Rust owns screen capture, bounded decoding and session-scoped actions. Svelte owns command entry and the result panel. A native generation plus frontend disposal prevents canceled scans from reopening the window. Reuse existing settings, clipboard, theme and global-shortcut infrastructure.

**Tech Stack:** Tauri 2, Windows GDI, ZXing-C++ Rust bindings, existing image crate, Svelte 5 and Vitest.
