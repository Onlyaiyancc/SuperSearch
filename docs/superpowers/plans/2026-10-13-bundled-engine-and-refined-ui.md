# Bundled file search and compact neutral UI

用户已选：无需额外安装 Everything，随 SuperSearch 附带后台搜索程序；紧凑浅色中性灰、细边框、更小字号与高度。保留中文、空输入仅搜索栏、呼出清空、成功打开匹配优先、Bing Enter/Shift+Enter、同一次运行拖动位置。

## UI

默认 680×60 逻辑像素，零外侧留白，无原生额外边框/阴影。中性色、12px 圆角、约 18px 输入字体与 20px 图标。结果继续每行 60px，整体高度 154+60×可见行数、最多 514；设置620。缩小不移除无障碍标签或快捷键能力。用户提供的现状截图作为审查证据，新增截图如工具失败必须注明，不用旧图冒充。

## 文件搜索

官方稳定 x64 Everything 1.4.1.1032 portable 随程序提供。SDK 继续使用已有静态链接 IPC 桥接，绑定独立 SuperSearch 命名实例。自有实例隐藏搜索窗口与托盘，配置和数据库独立存于本应用目录；禁用更新、HTTP/ETP 和查询/运行历史，不改现有 Everything 客户端、服务或数据库。

始终使用普通用户可用的文件夹索引：默认可访问的固定磁盘根目录，或用户选择的包含目录。拒绝无效路径、空的可访问指定范围与范围扩大。禁用卷自动包含并连接不可用的独立服务管道，不借用现有服务，以免上游默认行为创建新 USN 日志。首次扫描较慢，状态应真实表达。此次不自动安装/升级系统服务，不自动提权。程序负责单实例启动、失败反馈和只结束自身管理的后台进程；外部 Everything 不受影响。

发行保留所用二进制的版权许可和第三方声明，记录官方下载地址、版本、SHA256/签名。不声称把 Everything 的闭源索引核心编成同一 Rust 进程，也不声称后台进程消失。

## 验证与交付

后端工作者负责引擎、原生启动/生命周期、命名 IPC 和有意义的回归；前端工作者负责外观与内置引擎服务设置；主代理负责官方包来源、原生尺寸、隔离引擎测试、打包和文档。需求和质量独立复核。测试隔离命名实例与测试目录，不终止共享 Everything、不改其配置、不对整盘进行测试扫描。
